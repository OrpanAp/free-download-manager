Zephyr is installed 🎉

One last step: add the Zephyr extension to your browser. It lets Zephyr catch your downloads and grab videos from web pages.

Did the black setup window (PowerShell) already do this for you?

Open your browser’s extensions page. If you can see Zephyr Integration in the list and it is switched on, you are finished — you can close this page.

If not (or the window closed with an error), follow the steps below. It takes about one minute per browser.

You can open this guide again any time: Start menu → Zephyr Download Manager → Installation guide. To run the automatic helper again: Start menu → Zephyr Download Manager → Install browser extension.

Before you start

  1. Make sure Zephyr is running. Look for its icon near the clock (click the little arrow ^ if you don’t see it). If it isn’t there, open Zephyr from the Start menu. The extension talks to the Zephyr program, so it must be open.
  2. Copy the extension folder path. You will paste it in a moment:
    C:\Program Files\Zephyr\browser-extension

    This is the folder that contains a file called manifest.json. Always pick this folder, not the one above it.

Add the extension to your browser

Choose your browser below. If you use more than one, repeat the steps for each. (Chrome, Edge, Brave, Vivaldi and Opera all work the same way.)

Google Chrome
  1. Open Chrome. Click the address bar at the top, type chrome://extensions and press Enter.
  2. In the top-right corner, switch Developer mode ON.
  3. Click the new Load unpacked button (top-left).
  4. A window titled “Select the extension directory” opens. Click in the Folder box at the bottom, press Ctrl + V to paste the path you copied, then press Enter and click Select Folder.
  5. Zephyr Integration now appears in your list, switched on. Click the puzzle-piece icon next to the address bar and the pin next to Zephyr so it is always visible.
Microsoft Edge
  1. Open Edge. Click the address bar, type edge://extensions and press Enter.
  2. In the left menu, at the bottom, switch Developer mode ON.
  3. Click Load unpacked (top).
  4. In the folder window, click the Folder box, press Ctrl + V, press Enter, then click Select Folder.
  5. Zephyr Integration appears in the list. Click the puzzle-piece icon in the toolbar and show it next to the address bar.
Brave
  1. Open Brave, type brave://extensions in the address bar and press Enter.
  2. Switch Developer mode ON (top-right).
  3. Click Load unpacked, paste the folder path with Ctrl + V, press Enter, then Select Folder.
  4. Check that Zephyr Integration is in the list and switched on.
Vivaldi or Opera
  1. Type vivaldi://extensions (Vivaldi) or opera://extensions (Opera) in the address bar and press Enter.
  2. Switch Developer mode ON.
  3. Click Load unpacked, paste the folder path with Ctrl + V, press Enter, then Select Folder.
Firefox (temporary — lasts until Firefox is closed)

Firefox only keeps unsigned extensions until you close it, so this has to be repeated each time. It also needs a slightly different setup file:

  1. Open File Explorer, open the extension folder (path above) and copy the whole folder to your Documents folder (you may be asked for permission).
  2. In your copy: delete manifest.json, then rename manifest.firefox.json to manifest.json.
  3. In Firefox, type about:debugging#/runtime/this-firefox in the address bar and press Enter.
  4. Click Load Temporary Add-on…, open your copy of the folder and choose the file manifest.json.

For a permanent Firefox install the extension has to be signed by Mozilla (free). If you built Zephyr yourself, see installer\README.md.

Check that it works

  1. Open any web page with a video and press play. A green “Download with Zephyr” button appears on the video when you move your mouse over it — click it. A Zephyr window opens.
  2. Or right-click any download link and choose Download with Zephyr.
  3. Normal file downloads (ZIP, EXE, PDF, MP3…) are caught automatically while Zephyr is running.

Something went wrong?

“Manifest file is missing or unreadable” You picked the wrong folder. Choose the folder named browser-extension that contains manifest.json directly inside it.
I can’t find “Load unpacked” Developer mode is still off. Switch it on first (top-right in Chrome/Brave, bottom of the left menu in Edge).
Nothing happens when I click the extension or a download Zephyr isn’t running. Start it from the Start menu and keep it open (it can stay in the tray). If you changed the “Browser port” in Zephyr’s Options, set it back to 9614 and restart Zephyr.
Chrome shows “Disable developer mode extensions” when it starts Normal for extensions added this way. Click Cancel (or X) to keep it. Installing it from the Chrome Web Store removes this message.
The button is greyed out / “Managed by your organization” Your work or school computer blocks extensions added by hand. Ask your IT administrator, or use Zephyr without the extension: copy a link and Zephyr will offer to download it.
The extension disappeared after updating the browser Repeat the steps above. If you moved or reinstalled Zephyr, choose the new browser-extension folder.

Zephyr works without the extension too: copy a download link and Zephyr offers to download it, or use Add URL inside Zephyr. The extension just makes it automatic.
